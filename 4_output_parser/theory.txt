Output parser - help convert raw LLM responses into structured formats like
JSON, CSV, Pydantic models, and more 
-str output parser
-json output parser
-structured output parser
-Pydantic output parser
most used 

StrOutputParser
-used to parse the output of LLM and return it as a plan string.

JSONOutputParser
- LLM -> json
- it dose not force a schemea

StructuredOutputParser
- helps extracts structured JSON data from LLM responses based on predefined field schemas.
- now we dont use it, it is deprecated and we use pydanticoutputparser instead of this

PydanticOutputParser
- structure output parser that use pydantic model to enforce schema validation
